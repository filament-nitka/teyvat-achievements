# Ачивки Тейвата

Трекер достижений Genshin Impact с короткими подсказками «как получить». Главная цель — найти, как собрать побольше ачивок и примогемов.

Сайт — один файл `index.html`, без сервера и сборщиков. Прогресс хранится в браузере у каждого пользователя.

## Что умеет

- 1558 ачивок (1854 ступени) из всех категорий книги достижений, с подсказками: с русской и английской Genshin Impact Wiki, переводы и черновики.
- Отметки кольцом прогресса (у многоступенчатых — по ступеням), кнопки «Отметить все» в папке с отменой.
- Счётчики: ступени как в игре и сколько примогемов ещё можно собрать.
- Фильтры: категории, теги, регионы (с прогрессом и примогемами по каждому), «Быстро / Средне / Долго», «Новое в версии», поиск.
- Вид «По заданиям»: пачки ачивок, которые закрываются одним заданием, по убыванию примогемов.
- «Что сделать сегодня?» — случайная невыполненная ачивка (можно только быстрые).
- «Сегодня не забудь» — ежедневный трекер для IRL-ачивок.
- Ссылки «Где это на карте» (вики) и «Метки на карте HoYoLAB».
- Импорт и экспорт прогресса в формате UIAF (совместим с paimon.moe, Seelie.me, Snap.Hutao и другими).
- Светлая и тёмная темы.

## Как выложить на GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое этой папки (вместе с `.nojekyll`).
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Для кнопки «Предложить правку» у каждой ачивки впишите адрес репозитория в `scripts/template.html` — константа `REPO` (например, `"https://github.com/<логин>/<репозиторий>"`) — и пересоберите `index.html`.

## Структура

```
index.html                     готовая страница (публикуется)
data/achievements.json         собранная база: ачивки, теги, подсказки, регионы, карты
data/source/                   исходные данные
  pm_ru.json, pm_en.json       тексты ачивок (paimon.moe)
  gdb_achievements.json        скрытость и порядок ачивок (выжимка из genshin-db)
  wiki_achievements.json       таблицы ачивок с русской и английской Fandom-вики
scripts/
  template.html                шаблон страницы (стили, логика)
  build.py                     data/source → data/achievements.json
  make_html.py                 template.html + achievements.json → index.html
  update_sources.py            скачать свежие pm_*.json и gdb_achievements.json
  fetch_wiki.py                собрать заметки с вики (опционально)
  pilot_hints.py               ручные подсказки (пилот по Инадзуме)
  hidden_hints.py              подсказки к скрытым ачивкам по страницам вики
  translate_en.py              перевод английских требований с вики
  wiki_maps.py                 страницы вики с разделом карты
```

Нужен только Python 3.10+. Для `fetch_wiki.py` дополнительно: `pip install requests beautifulsoup4`.

## Как править и пересобирать

Все команды — из корня репозитория.

- Поправить подсказку или перевод: отредактируйте `scripts/pilot_hints.py`, `scripts/hidden_hints.py` или словарь `MANUAL` в `scripts/translate_en.py`.
- Поправить вёрстку или логику страницы: `scripts/template.html`.
- Пересобрать:

```
python3 scripts/build.py
python3 scripts/make_html.py
```

`build.py` в конце печатает отчёт: сколько ачивок без подсказки, без тегов, по регионам и т. п.

## Как обновить базу под новую версию игры

1. `python3 scripts/update_sources.py` — скачает свежие тексты ачивок и выжимку genshin-db.
2. Обновите `data/source/wiki_achievements.json` — таблицы с вики. Это таблицы со страниц категорий ачивок на genshin-impact.fandom.com (русская и английская вики); их проще всего собрать через браузер (например, попросить Claude с расширением для Chrome), формат — как в текущем файле.
3. `python3 scripts/build.py && python3 scripts/make_html.py`.
4. Новые ачивки автоматически получат метку «Новое» и фильтр «Новое в X.Y». Посмотрите в отчёте `build.py`, у каких ачивок нет подсказки или тегов, — свежие обычно там.
